# Edge agent

`apps/edge-agent/agent.py` is a CPU-first simulator for capture, offline queueing, health events, failure modes, sync, and cache-safe behavior. Commands include `run-demo-mission`, `simulate-capture`, `queue-status`, `set-offline`, `set-online`, `sync-now`, `health`, `simulate-failure`, `list-jobs`, and `clear-cache-safe`. It does not connect to physical hardware.
