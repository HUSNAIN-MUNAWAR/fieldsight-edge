# Roadmap

1. Managed PostgreSQL/PostGIS and spatial indexes.

3. Signed webhooks and configured integrations.
4. Local ONNX/YOLO adapter implementation with managed weights.
5. Device provisioning, secure enrollment, and signed update delivery.
6. Centralized observability, backups, data retention, and incident-response controls.
