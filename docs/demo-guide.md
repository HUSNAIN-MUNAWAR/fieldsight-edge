# Demo guide

1. Sign in as Organization Admin.
2. Open Mission Control and use the workspace selector.
3. Open Map, inspect a critical finding, then Review Queue.
4. Verify the finding, create an approval-gated work order, attach synthetic resolution evidence, and verify.
5. Use Edge Fleet or edge-agent to simulate offline capture, failure, reconnect, sync, media validation, inference, and review entry.
6. Open Asset Risk, Change Explorer, Data Quality, Alerts, and Reports.
7. As Data Scientist, create a candidate, run a synthetic evaluation, and stage/rollback a control-plane deployment simulation.
