# Code of Conduct

## Our standard

We want FieldSight Edge to be a respectful, technically serious, and welcoming project. Participants are expected to:

- Be constructive, specific, and professional.
- Assume good intent while still giving honest technical feedback.
- Respect different experience levels and communication styles.
- Focus criticism on ideas, code, and behavior rather than people.

## Unacceptable behavior

- Harassment, intimidation, discrimination, or personal attacks.
- Doxxing, threats, or sustained hostile behavior.
- Deliberate misrepresentation of another contributor's work or intent.
- Spam, trolling, or disruption that prevents healthy collaboration.

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, pull requests, or other contributions that violate this code of conduct.

## Reporting

If you experience or witness unacceptable behavior, open a private GitHub security advisory or contact the maintainers through the repository's security policy workflow when appropriate. If the issue is not security-sensitive, use a standard GitHub issue and clearly mark it as a conduct concern.
